Welcome to My Manga App. My app brings you the latest and most popular manga titles, allowing you to dive into the world of Japanese comics and track what you have read with ease. The app is currently using the mangadex api to get covers and data about certain manga and is using react natvie to display it. I am using zustand and aysncstorage to store history and themes I will be planning to add more features such as likes and more apis for more mangas as well as way to read the manga chapters.
